# claude-tema — темы оформления для Claude

Мод `tema` меняет оформление приложения Claude (десктопного и мобильного): цвета интерфейса и живой фон за чатом. Внутри пять тем, у каждой есть светлый и тёмный вариант — приложение само берёт тот, что подходит к его режиму.

| № | Тема | Как выглядит |
|---|------|--------------|
| 1 | Космос | ночное небо: мерцающие звёзды, планета с кольцом и падающие звёзды; в светлом режиме — лавандовый рассвет |
| 2 | Бумага | тёплая бумага днём, бумага под лампой ночью |
| 3 | Хвоя | спокойная хвойная зелень: светлый мох днём, тёмный лес ночью |
| 4 | Сакура | нежно-розовая днём, тёмно-вишнёвая ночью |
| 5 | Блочная зима | новогодняя ночь из блоков: северное сияние, ёлка с гирляндой, подарки, снеговик и падающий снег; в светлом режиме — снежный день |

Рисунки сцен — собственная пиксельная графика в блочном стиле: персонажей, текстур и логотипов игр в моде нет.

## Установка

В терминальной сессии Claude Code:

```
/plugin install tema --marketplace PaelPelmeny/claude-tema
```

На вопрос `Add marketplace?` ответь `y`, затем выбери область `user` (она первая в списке) клавишей Enter — так мод будет работать во всех сессиях.

Из обычной командной строки:

```
claude plugin install tema --marketplace PaelPelmeny/claude-tema
```

В приложении Claude, где `/plugin` не работает: нажми **+** рядом с полем ввода → **Plugins** → **Add marketplace**, введи `PaelPelmeny/claude-tema`, затем **Add plugin**.

Если чат был открыт ещё до установки, отправь в нём `/reload-plugins` или просто начни новый чат.

## Как пользоваться

- `/tema` — список тем, текущая отмечена
- `/tema 5` или `/tema зима` — включить тему по номеру или по названию
- `/tema дальше` — следующая тема по кругу
- `/tema выкл` — вернуть стандартное оформление

Выбор запоминается между сессиями. Темы видны в десктопном и мобильном приложении Claude; в терминале оформление не меняется, а окна запроса разрешений всегда остаются в стандартном виде.
